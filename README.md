# Channel 8 (Android TV)

Minimal Google TV / Android TV app that launches straight into full-screen playback of a live HLS stream.

- Stream server: change `BASE_URL` in `app/src/main/java/tv/channel8/app/Config.kt`
  (and the host in `app/src/main/res/xml/network_security_config.xml`, which scopes cleartext HTTP).
- On launch it fetches `BASE_URL/playlist.m3u`, plays the first entry, and shows a
  "Channel 8 — reconnecting…" screen with back-off retries whenever the stream or server drops.
- Branding is generated by `branding/make_logo.py` (Pillow).

CI (`.github/workflows/build.yml`) builds a signed release APK on every push and uploads it as the
`channel8-apk` artifact. Signing secrets: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
